# 总剧本的写法

总剧本整部作品一份，管「讲什么」，相当于日漫的プロット加剧本。镜头、构图、表演留给每一条的分镜草稿（draft_strip 写），这里不写。

文件放在 `output/scripts/作品名.md`，按下面的顺序写。

## `# 《作品名》总剧本`

### `## 企画`
- 一句话梗概：谁、想要什么、遇到什么、最后怎样。
- 主题，以及读者读完应该有什么感受。
- 篇幅：几条、几章。

### `## 角色表`
- 每人一条：名字（和 select_characters 里的名字一致）、年龄身份、性格、说话方式、习惯动作。
- 不同时期的外观变化（发型、衣着）。

### `## 场景表`
- 反复出现的场景：在哪、什么年代、关键陈设和它们的相对位置（门在哪边、桌子朝哪），常见的时间和光线。

### `## 画面总则`
- 生成每一条时，这一节会原样附给生图模型：画风、线条、上色和色调、人物比例、地域和年代特征、对白框和旁白框的样式、文字语言。
- 只写要画成什么样，不写剧情上的禁忌。生图模型看到「不要画 X」反而容易画出 X。
- 可以从项目的 style.md 里提炼，但只留画面上的规则。

### `## 节奏表`
- 每条一行：
  - 作用：铺垫 / 推进 / 转折 / 高潮 / 余韵；
  - 情绪强度：1–5；
  - 版式结构：从 panel-layout 技能的结构清单（A–J）里选一个代号，写上为什么；
  - 读者须知：读完这一条，第一次看的读者必须知道什么（一句话）；
  - 时间线切换：如果这一条和上一条之间跳了时间或地点（例如从现在跳回童年），写明用什么方式过渡（见下面「时间线交错」）。
- 结构的分配：
  - 相邻两三条不重复。
  - 特殊结构（C 断ち切り + 重ねゴマ、D コマまたぎ、I 斜め、大片白場）留给章节开头和情绪最高的几条；平时用 A、B、E、F、G、H、J 换着来。
  - 同一个地方再出现时，可以用同样的结构做「回声」。

### 每一条：`## 第N条｜标题`
标题必须这样写，draft_strip 按这个标题找到这一条。每条写四项：
- **情节点**：按顺序写这一条发生了什么，最后落在哪里，不写机位和构图。一条只讲一个场景，登场人物最好不超过 3 个。
- **台词与旁白（定稿）**：每句写明谁说、原文是什么。分镜草稿只引用、不改写，所以这里就要写成最终的样子。
  - 手机上看，一个框最多两行、每行十来个字，长的拆开。
  - 一条的对白框最好不超过 6–8 个。
  - 旁白不做解说，画面能说清的就不写。
- **必须出现的画面**：剧情需要的具体东西，例如站牌上要看得到「南京」。只写剧情需要的内容，不规定版式手法（哪一格出血、小格里放什么），那是分镜草稿的事。
- **读者须知**：读完这一条，第一次看的读者必须知道的事，一条一行。
  - 新登场的人物是谁、和「我」什么关系（例如：姑姑是家里人，常来吃饭）；
  - 这一条用到的称呼和说法是什么意思（例如：小炮子子是男孩的叫法，「我」被叫作小炮子子）；
  - 现在是什么时候、在哪里（尤其是刚从别的时间、地点跳过来时）。
  draft_strip 起草和 review_comic_strip 检查时都会对照这一项。

章节可以用 `# 第一章 标题` 分开。只做一两条时也照这个格式写，只是短一些。

## 改编原文的规则（コミカライズ）
把小说、散文改成条漫时，原文的每一句信息要么写进定稿文字，要么交给画面，读者不能因为删节而少知道什么。删一句之前先查：后面有没有句子要靠它才读得懂。
- **必须保留的**：
  - **称呼和说法的定义**。例如「小孩就叫小孩，男孩叫小炮子子，女孩叫小姑娘」。删了它，「我是小炮子子」就落不下来，「喊小姑娘的时候，大人的声音要软一截」也失去了对照。
  - **代词指的东西**。例如「它们没有形状，也不往哪块去，就是晃」，前面必须有「太阳从叶缝里漏下来，碎成一块一块的光」。
  - **前因后果**。例如「南京人说阿是，我们说个是」前面的「县城里的人说话跟南京话差不多」，以及「不要就挤成了表」前面的「话说得快，两个字常常挤成一个」。
  - **原文里能当画面的事件**。例如「谁家小孩哭了，大人一张嘴就是表哭表哭」。它不是可以删的补充事件，而是把抽象的说明变成画面的那一幕。
  - **点明人物关系的句子**。例如「姑姑常过来吃饭」要和她坐到饭桌边、被家人招呼的画面放在一起。
- **可以删的**：重复的修饰、和主线无关的枝节。删了以后，读者不会少知道什么。
- **可以重排顺序**：但每一句要和它说明的东西留在同一条里，不要把前提留在第 2 条、结论挪到第 3 条。
- **一条要自足**：只读这一条和前面几条，就能读懂这一条的每一句话。

## 时间线交错（现在 ↔ 回忆）
- **每次切换都要交代**：读者要立刻知道「时间跳了」和「这是同一个人」。在节奏表里写明这一次用哪种过渡：
  - **触发**：现在的一句问话、一个声音、一件东西，把人带进回忆。
  - **つなぎ**：用同一个角度的脸、同一个动作或同一件东西，把两个时间接起来。例如成年人放在膝盖上的手，切到孩子扶着凳子的手。
  - **标注**：一句时间或地点标注，例如「那年夏天」「现在」。标注算定稿文字，写进这一条的台词与旁白。
  - **视觉记号**：现在和过去用固定的色调或边框区分（例如现在偏冷、过去偏暖），全篇不变。
- **大人和孩子是同一个人**：至少在第一次切换时，用つなぎ让读者看出来，不要只靠读者自己猜。
- **回到现在**：用和上次一样的构图（同ポジ）或同一个场景的引き，读者马上认得出「又回来了」。

## 例子（骨架）

```markdown
# 《门口》总剧本

## 企画
- 一句话：放学后，小樱在教室门口等一个不会来的人。
- 读完的感受：安静的失落。
- 篇幅：3 条，1 章。

## 角色表
- 小樱：十岁，小学四年级；话少，紧张时揪书包带。

## 场景表
- 教室门口：走廊朝西，傍晚光从窗户斜进来；门在画面右边。

## 画面总则
- 清淡配色，细腻线条，自然人物比例。
- 圆形对白框，方形旁白框，中文。

## 节奏表
- 第1条：铺垫，情绪 2，H 横長叠加（放学后慢慢空下来的走廊）；读者须知：小樱放学后一个人留在教室门口
- 第2条：转折，情绪 4，B L 形（小樱站在门口，面前两件事）；读者须知：她在等的人不会来了

## 第1条｜放学
- 情节点：铃响，同学陆续离开，小樱留在门口。
- 台词与旁白：
  - 旁白：放学铃响了。
  - 同学：「小樱，走吗？」
- 必须出现的画面：走廊尽头的窗。
- 读者须知：放学了；小樱一个人留在门口。
```
