# 分格与版式（コマ割り）

コマ割り不是排版，是演出。格子替读者决定三件事：
- **时间**：在这里停多久；
- **距离**：离人物多近；
- **分量**：这一下有多重。

读者不会意识到格子的存在，只会觉得「这里慢下来了」「这一下好重」「好空」。分格就是在设计这些感觉。

## 三条原则
1. **先有情绪，再有格子**：先写清这一条的情绪曲线（平静 → 不安 → 落下，或者日常 → 一个细节 → 余韵），再决定每一格的大小、形状和間白。格子跟着情绪走，不是跟着画面里东西的多少走。
2. **一条只有一处形状上的看点**：断ち切り、コマまたぎ、変形ゴマ这类特殊处理，一条用一处，最多两处，其余保持朴素，看点才响。处处都特殊，就等于没有看点。
3. **方格不等于单调**：日漫一页里大部分格子是方的。单调来自同样的大小、同样的段落结构、同样的景别。靠大小差、长宽比、段的组合和镜头变化就能做出节奏；特殊处理是最后才加的调味。

## 术语
这些是编辑和作者之间用的说法，后面的手法和结构都用这套说法。

| 术语 | 意思 |
|---|---|
| コマ割り | 分格：一条怎么切成格子，每格多大、什么形状、怎么排 |
| 段 | 一横排格子（tier）。竖条一般是 3–5 段 |
| 大ゴマ / 小ゴマ | 大格 / 小格 |
| キメゴマ | 这一条决定性的一格，也叫看点格、主役のコマ，是全条最强的一格 |
| タメ | 看点之前的蓄势：把读者的呼吸收紧，让キメゴマ落下时更重 |
| 間（ま） | 停顿：一格没有文字、没有动作，或者一条变宽的間白 |
| 余韻 | 看点之后的回响：拉远、无声、留白 |
| ヒキ | 结尾把读者拉向下一条的钩子（和镜头上的「引き」不是一回事） |
| 間白（まじろ） | 格与格之间的白色格缝（gutter） |
| 断ち切り（タチキリ） | 画面一直延伸到页边，格框被裁到页边以外（bleed） |
| 枠なし | 不画格框，画面直接放在白底上 |
| はみ出し | 人物或物件越出格框 |
| コマまたぎ | 一个人物或一个对白框跨过几格，压在格框和間白上 |
| 重ねゴマ | 大格上叠一个小格（inset panel），放同一时刻的另一层：手、物件、表情（这是这里的叫法） |
| 同ポジ | 同一个机位、同一个构图重复出现，只改一点点（来自动画的说法） |
| 変形ゴマ | 非矩形的格：斜め（斜切）、台形、円形、角丸 |
| 寄り / 引き | 推近 / 拉远 |
| アオリ / フカン | 仰拍 / 俯拍 |
| ナメ | 隔着前景拍，例如肩ナメ就是过肩镜头。前景越近，读者越像在偷看 |
| イマジナリーライン | 人物之间的轴线，跨格不能越轴 |
| 視線誘導 | 用人物的视线、动作方向、对白框的位置，把读者的眼睛带到下一格 |
| 白場（しろば） | 页面上刻意留下的空白 |
| 心象風景 | 用风景表现人物的内心 |

## 每种手法传达什么情绪

### 1. 大小差：时间和分量
- **大ゴマ**：时间停住，分量最重，读者在这里停得最久。给キメゴマ、第一次看见某个地方、情绪最满的那一下。
- **小ゴマ**：一瞥、一拍、一个细节，节奏快。连续的小格等于把时间切碎，读出来是紧张、犹豫、心跳。
- **用法**：タメ那几格逐渐变小，读者的呼吸跟着收紧；到キメゴマ突然放大，情绪一下子压下来，或者一下子松开。大小差越大，冲击越强。克制的作品也要有差，只是不必走到极端。
- **参考数字**：キメゴマ至少占页面高度的三成，最小的格不到它的一半。
- **大格里放什么，看要读者看什么**：
  - 看表情，就给特写一个大格，情绪直接压到读者面前。
  - 看人和世界的关系，就给远景一个大格，人被世界包围，读出来是孤独、渺小、辽阔。

### 2. 长宽比：视线的方向
- **横長ゴマ（扁长格）**：视线横着扫过去，读出来是时间在流、平静、日常，也适合横向的移动和距离（比如两个人隔着一张桌子）。几个整宽的横長ゴマ叠在一起，像呼吸均匀的叙述。
- **縦長ゴマ（竖长格）**：视线上下走，读出来是静止、伫立、高度（仰望、坠落），也是孤立（一个人站在窄格里），或者压迫（头顶压着东西）。
- 一个竖长格夹在几个横格之间，就是一个「站住」的时刻。

### 3. 段的组合：节奏的骨架
- **一段一格（整宽）**：叙述、交代，节奏平稳。
- **一段两格**：对比、对话、动作和反应、因果。
  - 两格等宽：两边对等。
  - 一宽一窄：有主次。宽的那格是事件，窄的那格是反应或细节。
- **一段三格**：只放没有字或字极短的小格，用来连拍、表现心跳和犹豫，时间被拉长又切碎。
- **L 形**：一个縦長ゴマ跨两段，放在左边；右边上下叠两格。
  - 竖格是一直在那里的状态：站着的人、一扇窗、一扇门。右边两格是在它面前发生的事。
  - 读者先读左边的竖格，再读右边的上、下两格。
- **跨段的大格**：一格跨两三段，打断段的节奏，留给キメゴマ。
- **别让结构变成套路**：每条都用同一种段落结构，读者会读出套路。

### 4. 間白：沉默的长度
- **同一段里的窄間白**：同一时刻、连续的动作，眼睛不停地往下一格走。
- **段与段之间的宽間白**：时间过去了、换场了、喘一口气。
  - 比平常宽一倍：「过了一会儿」。
  - 更宽，几乎成了白場：「过了很久」「什么都没发生」。
- **没有間白（格子紧贴或重叠）**：同一瞬间的不同侧面，或者情绪不留缝隙地涌上来。少女漫画常用。
- **黑色間白、黑底**：回忆、夜晚、压抑、不在场。
- **用来表现缺席、空白、等待**：把間白加宽，让白色本身成为情绪。

### 5. 断ち切り：世界溢出格子
- **做法**：画面不画外框，一直延伸到页边。我们的条漫是一张 9:16 的图，就是延伸到图的边缘。
- **情绪**：画面比格子大，读出来是辽阔、沉浸、被世界包围，或者情绪大到格子装不下。常用于风景、季节、第一次看到某个地方、キメゴマ。
- **克制的作品**：用断ち切り的风景做余韻很有效：人很小，世界很大。
- **注意**：文字放在离图边远的安全区。一条最多一处。

### 6. 枠なし：不在此刻的时间
- **做法**：不画格框，人物、风景或物件直接放在白底上，边缘自然淡出；也可以是只有人物、没有背景。
- **情绪**：格框代表「此刻、此地」，拿掉框，画面就从叙事里脱开，变成「不在此刻」或者「在心里」：回忆、心声、梦、余韻、对某个人的印象，也用于人物出场和独白。
- **克制的作品**：这是主力手法之一，安静、轻、留白多。
- **注意**：一条用一两处。无框人物旁边的旁白框可以漂在白場里。

### 7. 重ねゴマ：同一时刻的另一层
- **做法**：在大格的一角叠一个小格（外面一圈白边，再加黑框），放同一时刻的另一层：手、物件、表情、一个细节。
- **情绪**：
  - 读者在看大场面的同时注意到一个小东西，就是「注意到了」的那一刻。
  - 亲密：远景上叠一只手的特写。
  - 藏起来的情绪：大格里的脸很平静，叠着的小格里手在发抖。
- **位置**：
  - 叠在大格的右下：读者读完大格才注意到。
  - 叠在左上：读者先看到细节，再看全景。
- **小格里放什么**：必须是某个人注意到的东西，或者剧情此刻需要读者看见的东西。
  - 用视线把它和人物连起来：大格里人物看向的方向，就是小格叠的位置；或者小格里就是人物的手、人物手里的东西。
  - 或者放在说到它的那句旁白的同一格。
- **不要这样用**：
  - 不要把蚊香、钟、杯子这类气氛物件单独叠成小格。它和人物没有关系，读者不知道为什么要看它，只会觉得突兀，还打断了场景的交代。气氛物件要么放进大格的画面里（前景飘过的一缕蚊香烟），要么给它一格完整的空镜，作为停顿。
  - 场景的第一格（交代格）不叠小格，让它完整地呼吸：读者要先看清在哪、谁在场。
- **注意**：小格不要压住大格的主体和文字。一条一处。

### 8. はみ出し：情绪越过边界
- **做法**：人物的一部分（头、手、发梢、衣角）或者一件物件越出格框，伸进間白或相邻的格。
- **情绪**：情绪溢出、存在感强、冲出来、向读者伸过来。也可以很轻：一缕头发越过格框，像心思飘了出去。
- **克制的作品**：只越出一点点，用在キメゴマ或情绪转折的那一格。
- **怎么交代**：在越出的地方画虚线轮廓并标上字母（见 layout-sketch 技能）。画面指令里写明越出的是什么、越到哪里。

### 9. コマまたぎ：一个人笼罩整个场面
- **做法**：
  - 一个人物不画框，大大地压在几格上面，通常占半边、跨两三段。
  - 被压住的格框和間白在人物身后断开。
  - 旁边的格子照常叙事。
- **情绪**：这个人的存在或心境笼罩了整个场面，旁边发生的事都成了「她眼里的」「她心里的」。适合登场、伫立、决心、回想、内心独白。少女漫画和日常系常用。
- **位置**：放在开始读的一侧（左边或上面）。读者先看人物，再读旁边的格子。
- **注意**：
  - 非常占地方，整部作品里只偶尔用，比如章节开头、情绪最高点。
  - 人物的姿势要简单有力（站着、侧脸、背影），表情克制。
- **对白框也可以コマまたぎ**：一句话跨过两格之间的間白，把两个画面连起来，这句话的余音落在下一格。

### 10. 同ポジ与被切开的一张画：时间流过同一个地方
- **同ポジ**：同一个机位、同样的构图连着两三格，只改一处（光线、人在不在、物件的位置）。读出来是时间流逝、等待、缺席、停滞：「什么都没变，只有那一点变了」。
- **一张画被間白切开**：一个连续的场景被切成几格。可以让同一个人在每格出现一次（走过一条街），也可以让镜头慢慢扫过一片全景。读出来是空间连着、慢慢看、陪人物走一段路。
- **注意**：同ポジ要真的「同」：机位和物件位置都一致，只改要改的那一处。画面指令里写清楚哪些不变。

### 11. 変形ゴマ：不安、速度、回忆
- **斜め（斜切的格线）**：不稳定、冲突、速度、心里一震。安静的场面不用。
- **台形 / 平行四边形**：有透视感，表现冲向读者或者远离读者的动势。
- **円形**：聚焦、回忆、一闪而过的念头，也可以是从门缝里、从眼睛里看到的东西。
- **角丸（圆角）**：柔和，适合回忆、梦、心声。
- **黑底格、暗角、柔边**：回忆、过去。
- **注意**：小学館的漫画讲座提醒过，变形格多用会难读。一条只用一种，留给转折、冲突、回忆的那一格。

## 情绪 → 版式（速查）

| 想让读者感到 | 优先用 |
|---|---|
| 平静、日常、生活在流 | 整宽的横長ゴマ、正常的間白、平视、背景画细 |
| 安心、温暖 | 两人在同一格、寄り、柔和的光、窄間白 |
| 不安、紧张 | 小格连续、格子变窄、間白变窄、寄り到局部、斜め（克制的作品可以不用） |
| 犹豫、心跳 | 一段三小格、同ポジ、表情或手的微小变化 |
| 孤独、空、缺席 | 大远景里的小人物、宽間白、白場、枠なし、同ポジ的空镜 |
| 回忆、过去 | 枠なし、角丸、柔边、黑色間白、颜色调淡、円形 |
| 情绪满溢、下定决心、受到震动 | 大ゴマ、断ち切り、はみ出し、コマまたぎ |
| 冲突、速度 | 斜め、台形、流线、小格快切 |
| 注意到一个细节 | 重ねゴマ、大特写的小格 |
| 时间流逝 | 同ポジ连排、宽間白、光线和天气的变化 |
| 余韻 | 拉远、无声、白場、断ち切り的风景 |

## 场景转换与回想（場面転換・回想の入り方）
读者在格子之间自己补上省略的东西（closure）。同一个场景里的动作，读者补得毫不费力；换了场景、跳了时间、进了回忆，补的距离就远了，必须给线索，否则读者就被扔下了。
- **换场景**：新场景的第一格用引き交代。前一个场景的最后一格和这一格之间，加宽間白。
- **时间跳过去**：用宽間白、光线和天气的变化（傍晚变深夜、夏天变冬天）；需要时加一句标注（「几天以后」「那年夏天」）。
- **进回忆：先触发，再接**：
  - 触发是现在的一句问话、一个声音、一件东西。例如医生问「第一次觉得自己不一样是几岁」，成年人的脸慢慢推近。
  - 然后用つなぎ切进去：
    - **顔つなぎ**：同一个角度、同样大小的脸，从大人换成孩子。读者一下子明白「这就是她小时候」，两个时间叠在一起的那一下最有力。
    - **動作つなぎ**：同一个动作。大人放在膝盖上的手，切到孩子扶着凳子的手。
    - **物つなぎ**：同一件东西。诊室桌上的笔，切到童年桌上的筷子；现在的风扇声，切到过去的老风扇。
    - **音つなぎ**：一个拟声词跨过切换的那一格，例如「嗡——」从现在的空调延续到过去的风扇。
  - 情绪：つなぎ让读者感到时间是连着的，过去还活在现在的这个人身上。
- **回忆的视觉记号**：现在和过去用固定的色调或边框区分（现在偏冷、过去偏暖；回忆的格子可以用柔边或角丸），全篇不变，读者学会一次就不会迷路。
- **出回忆**：回到进去之前的同ポジ（同样的诊室、同样的机位），或者让回忆里的最后一句话落在现在的画面上，读者马上知道「回来了」。
- **注意**：不要连续切换太快。每次进出回忆，至少给读者一格在新的时间里站稳。

## 情绪曲线怎么落到格子上
- **起（开场）**：一段整宽的横長ゴマ，用引き交代时间和地点；或者有意接住上一条的最后一格。
- **承（推进）**：段的组合开始变化（两格并排、对话和反应），格子大小正常。
- **タメ**：格子变小、变窄，景别推近（寄り），間白变窄，节奏变快，把读者的呼吸收紧。
- **转（キメゴマ）**：全条最大的一格，或者用上这一条唯一的特殊处理（断ち切り、はみ出し、コマまたぎ）。
- **结（余韻 / ヒキ）**：拉远、无声，加宽間白或留出白場；或者留一个小钩子：一个没说完的眼神、一件物件。

## 常用版式结构（选一个，再按这一条的情绪调整）
「→」表示往下一段，「并排」表示同一段里的几格。

| 代号 | 结构 | 情绪和适合的场面 |
|---|---|---|
| A 叙述型 | 整宽开场 → 两格并排 → キメ大格 → 窄收尾 | 平稳推进、一个落点。最常用，相邻几条不要都用它 |
| B L 形 | 左边縦長ゴマ跨两段，右边上下两格 → 整宽一两段 | 一个人站在那里，面前发生两件事；伫立、等待、对峙 |
| C 断ち切り + 重ねゴマ | 断ち切りの大格（风景或场面），上面叠一个小格 → 一两段方格 | 世界很大，人物注意到一个小东西；到达、发现、亲密。小格里是人物看着、拿着的东西，视线要连着；不要叠在场景的第一格，不叠气氛摆设 |
| D コマまたぎ | 左边一个无框的全身人物跨两三段，右边三格 → 整宽收尾 | 人物的心境笼罩整个场面；出场、独白、决心、回想 |
| E 同ポジ三连 | 整宽开场 → 同ポジ的三格（一段三格，或者三段扁格）→ 大格 | 时间流逝、缺席、等待 |
| F 枠なし交替 | 方格 → 枠なしの人物或物件 → 方格 → 枠なし | 心声、回忆和现实交替；安静、轻 |
| G 连拍 → 大格 | 一段三小格（无字）→ 两格并排 → キメ大格 | タメ很强的一条：犹豫、心跳，然后落下。不要用在作品或场景的开头：读者还不知道在哪、是谁，就先看到碎片 |
| H 横長叠加 | 四五个整宽扁格，間白宽 | 平静，时间缓慢流过；克制作品的「静」，但不要连着两条都用 |
| I 斜め | 斜切的格线切开两三格 → 方格 | 冲突、震动、速度；整部作品里很少用 |
| J 切开的一张画 | 一个连续的场景被間白切成两三格 → 方格 | 陪人物走一段路、慢慢看一个地方 |

## 阅读顺序（从左往右、从上往下）
- **基本**：同一段里从左到右，读完一段再往下（Z 字）。同一段里的間白窄、段与段之间的間白宽，眼睛自然走 Z 字。
- **L 形**：竖长格放在左边，也就是开始读的一侧。先读它，再读右边上、下两格。不要把竖长格放在右边、左边叠两格，读者会读乱。
- **重ねゴマ**：按它在 Z 字路径上的位置读：叠在大格右下角，就是读完大格之后读；叠在左上，就先读。
- **コマまたぎの人物**：放在左边或上面，读者先看人物，再读旁边的格子。人物身上不要放必须按顺序读的文字。
- **对白框**：同一格里先说的放左上；跨在間白上的对白框，算在尾巴指向的那一格。
- **格内的时间方向**：同样从左往右：先发生的、先说话的放在左边；人物朝右是往前，朝左（回头）是回望。

## 整部作品的版式节奏
- **按条分配结构**：总剧本的节奏表给每一条分一个结构代号（A–J），相邻两三条不要重复。
- **特殊处理留给少数几条**：断ち切り、コマまたぎ、変形ゴマ、大片白場，留给章节开头和情绪最高的几条；平时靠大小差和段的组合。
- **做回声**：同一个地方再出现时，可以用同样的结构或者同ポジ，读者会感到「又回到这里了」。
- **安静的段落也要变**：H（横長叠加）和 F（枠なし交替）换着用，不要连着用同一种。

## 生图模型的特点
- **跟得住结构，跟不住比例**：
  - 它跟得住「几段、每段几格」和格子的形状。圆形、斜切、角丸、はみ出し都测过，能照着画。
  - 它跟不住精确的高度比例，会把格子高度往平均拉。
  - 所以要强调的那一格，除了做得更大，还要靠形状或特殊处理让它「不一样」。
- **特殊处理要两边都交代**：枠なし、断ち切り、重ねゴマ、はみ出し、コマまたぎ，要在版式草图上按约定标出来（见 layout-sketch 技能），也要在画面指令里写清楚：是谁、越过了哪里、格框在哪里断开。
- **没画出来就修**：某个特殊处理没画出来，用修图补（strip-fix 技能），不用整条重画。
