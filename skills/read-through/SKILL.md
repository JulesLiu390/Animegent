# 连读（通読）

单条检查只能看出这一条画得对不对。读者是一条接一条读下来的：
- 人物在哪一条第一次出场？
- 一个说法在哪里解释？
- 时间在哪里跳过去？

这些只有连起来读才看得出来。日本的编辑看一整话的ネーム，一定会从头到尾通读一遍，看第一次读的人能不能跟上。单页漂亮、连起来看不懂，是最常见的退稿理由。

连读分两个阶段，都要做：
- **草稿连读**：一组分镜草稿写完、生成之前。这时候改最便宜，问题多半在总剧本和草稿里。
- **成图连读**：一组条漫生成以后。这时候看的是读者真正会看到的东西，包括生图模型画偏的地方。

一次最多读 12 条。更长的作品分组读，组和组之间重叠一条（比如 1–12、12–23）。后一组要把上一组复述的故事传进 previously（前情）：读者是从头读下来的，不带前情，前面已经交代过的人物、称呼、前提都会被当成「没交代」报出来，改了反而啰嗦。

## 第一步：当第一次看的读者
- 只看传进来的内容：草稿连读看「画面指令」和文字，成图连读看图；分组读时再加上前情。不要用你知道的剧本去补读者看不到的东西。
- 按顺序读完，然后用几句话复述你读到的故事：在哪、谁、发生了什么、「我」是什么样的人、最后落在哪里。复述里含糊、说不出、说错的地方，就是读者会卡住的地方。
- 每一条都回答：
  - 这一条在哪、什么时候？和上一条比，时间、地点变了没有，看得出来吗？
  - 每个人是谁、和「我」什么关系？第一次出场时看清了吗？
  - 每句话、每个称呼、每个「它」「她」都读得懂吗？

## 第二步：当编辑，找跨条的问题
- **人物登场**：每个人第一次出场的那一条，有没有看清脸、看出关系？后面再出场时还认得出吗（服装、发型、年龄）？
- **称呼和说法**：在哪一条第一次出现、在哪里解释？有没有先用后解释，或者根本没解释？
- **时间线**：每次切换（现在 ↔ 回忆、换场、跳时间）有没有交代？大人和孩子是同一个人，读者看得出来吗？回到现在时认得出吗？
- **连续性**：同一个场景前后，人物位置、衣服、道具、光线、时间一致吗？同一个人在这一组里的衣服前后对得上吗（没在服装表里安排的换衣服，读者会以为换了人）？
- **情绪曲线**：一组读下来，起伏是不是按节奏表走？有没有几条连着一样平，或者高点挤在一起？
- **重复**：版式结构、构图、镜头、特殊手法、句式，有没有连着几条重复，读出了套路？
- **文字量**：有没有哪条字太多、读起来累，或者字太少、看不懂？
- **读者须知**：对照总剧本节奏表里每条的读者须知，每一项读者真的知道了吗？

## 每个问题写什么
- **strip**：第几条（按传进来的顺序）；panel：第几格，跨条的问题写 0。
- **kind**：读不懂 / 衔接 / 人物 / 称呼 / 连续性 / 节奏 / 重复 / 文字 / 其他。
- **problem**：读者卡在哪里，写读者的感受（「看到这里不知道这个女人是谁」），不要写技术术语堆砌。
- **target**：根在哪里，选一个：
  - 总剧本：定义句、前提句被删了，时间线没有安排过渡，人物关系没有交代；
  - 草稿：缺交代格，旁白放错了格，特写没有交代它属于谁，版式和别的条重复；
  - 成图：草稿写对了，但画出来不对（只露了腿、画错人、字错了）；
  - 不用改：读者能懂，只是不够好。
- **fix**：最小的改法，具体到哪一条哪一格。例如「改草稿：第 3 条第 2 格让姑姑走到饭桌边坐下，奶奶给她添碗筷」「改总剧本：第 3 条加回『小孩就叫小孩，男孩叫小炮子子，女孩叫小姑娘』」。

## 结论
- **pass**：第一次看的读者能顺着读下来，复述的故事和本意一致。
- **minor**：有几处卡顿，但不影响读懂主线。
- **redo**：读者跟不上主线：不知道谁是谁、不知道时间跳了、主题句落空。

## 不要做的事
- 不要挑细节：手指的姿势、换行的位置、构图差几厘米，这些不影响连读，不报。
- 不要报前情里已经交代过的东西：那是分组读造成的，不是读者会卡住的地方。
- 不要把每个问题都推给成图：根在总剧本和草稿的，修图修不好，越修越碎。
- 问题要少而准：先报最影响读懂的五六个，其余的合并或者不报。
