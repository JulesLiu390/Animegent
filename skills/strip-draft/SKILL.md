# 分镜草稿（ネーム）的写法

## 草稿在流程里的位置
- **日本漫画的流程**：企画 → 大纲（プロット）→ 剧本 → ネーム（分格、镜头、人物位置和表演、对白框位置）→ 作画 → 编辑检查。ネーム是试错最多、编辑看得最仔细的一步。
- **这里的对应**：分镜草稿就是文字版的ネーム（字コンテ）。
- **为什么要写具体**：草稿交给生图模型作画，它只会画写出来的、看得见的东西，不会替你想镜头、表演和节奏。所以要具体到「照着就能画」。

附带的文件：
- `template.md`：草稿的格式，英文界面用 `template.en.md`。
- `checklist.md`：编辑检查清单。
- `sources.md`：这些规则的出处。

draft_strip 会自动附上格式和清单；手动修改草稿时，用 skill_read_resource 读。
template.md 里的「## 构思」「## 版式」「## 自检」「## 画面指令」和「### 第N格」这些标题由程序解析，改格式时不要改这几个标题的名字。

## 一条的结构
- **一条是什么**：一张 9:16 竖图、4–6 格，从上往下读，同一行从左往右读。
- **只讲一件事**：一条只讲一个场景、一件事。中途要换场就明确标出来：加宽格距、换光线，或者加一格交代新地点。
- **从结尾倒推**：先定读完要留下什么情绪，再定最后一格（落点还是余韵）和看点格（主役のコマ），最后才分格。
- **视点和人物**：这一条从谁的角度看，中途不换。登场人物最好不超过 3 个，左右站位全条不变。
- **起承转结**：
  - 开头：第 1–2 格要让人认出主角和他的处境；至少一格用背景交代时间和地点，或者有意接住上一条的最后一格。
  - 转：看点放在「转」附近，是全条最大的格，可以占到半页左右。
  - 结尾：最后一格要落下来，可以是一个反应、一个余韵或一个转折，不能停在半路。
- **每一格都要有新信息**：两格说的是同一件事（例如连着两格都是孩子贴着门听），就合并，或者换成新的东西：一个反应、一个细节、一段空镜。
- **间（ま）**：
  - 格少时间就快，格多时间就慢。情绪重的地方要放慢：多给一格、插一格旁人的反应，或者加宽格距、留白。
  - 每条至少一格无声（没有任何文字），用来停顿和看表情。
  - 安静的生活流常用风景或小物件的空镜收尾，或者拉远、无声。

## 交代：让第一次看的读者跟得上
编辑看ネーム最常写的批注是「谁是谁看不出来」「这是哪里」「时间跳了没感觉到」。单条漂亮、连起来看不懂，是最常见的退稿理由。草稿写完，要用一个没读过总剧本的读者的眼睛再读一遍。
- **先引后寄（状況説明）**：
  - 场景开头，以及每次时间、地点切换之后，第一格（最多到第二格）用引き交代在哪、什么时候、谁在场，再进细节。
  - 想先给特写制造悬念，下一格必须马上拉远揭开。
  - 作品和章节的第一条，不要用没有字的局部碎片开场。读者还不知道在哪、是谁，就先看到一只手、一支笔，只会一头雾水。
- **人物第一次出场**：
  - 要看得清脸和全身，并且同时交代关系。
  - 用表演交代：她走到饭桌边坐下，奶奶给她添碗筷，她摸摸孩子的头。或者把点明身份的那句旁白放在她清楚出现的这一格。
  - 只露腿、只露手、只露一截裙子的格子，不能用来介绍人物。
- **字画对应**：
  - 每句旁白放在说同一件事、或者同一时刻的那一格。「大人要去大城市，去的多半是南京」不能配奶奶端菜的画面。
  - 画不出来的信息换成画得出来的场面。比如方言：画小孩哭、大人弯腰说「表哭」。
  - 一格里的两句旁白要说同一件事，不要在一格里叠两个话题。
- **特写和插入（インサート）**：
  - 只放在交代过它属于谁、在哪的格子后面，或者马上接一格交代。
  - 它要回答读者此刻的问题：她在看什么？手在做什么？
  - 不能只是摆一个气氛物件。蚊香、钟、杯子这类东西放进大格的画面里，不单独拎出来。
- **称呼、说法、代词**：
  - 称呼和说法第一次出现的那一条，要在附近交代它的意思（用总剧本里的定稿句子）。
  - 「它们」「她」「那时候」这类词要在同一条里有着落。
- **回忆的进出**：
  - 进回忆：要有触发（一句问话、一个声音、一件东西），加一个つなぎ（同一个角度的脸、同一个动作、同一件东西）。
  - 出回忆：回到之前的同ポジ。
  - 现在和过去用总剧本规定的视觉记号区分。
  - 怎么接，按总剧本节奏表里写的过渡方式，见 panel-layout 技能的「场景转换与回想」。
- **对照读者须知**：总剧本这一条的「读者须知」，每一项都要在画面或文字里交代到。

## 分格（コマ割り）
每种分格手法传达什么情绪、常用的版式结构（A–J）、从左往右的阅读顺序约定，都在 panel-layout 技能里，draft_strip 会一起附上。写「版式」一节时按它来，这里只留几条硬规则：
- **先有情绪，再有格子**：先定这一条的情绪曲线（タメ → キメゴマ → 余韻），再定格子。
- **结构**：用总剧本节奏表分给这一条的结构代号；没有分配时自己选一个，并避开上一条用过的。
- **大小差**：キメゴマ至少占页面高度的三成，最小的格不到它的一半。等大排列没有重点。
- **一条只有一处形状上的看点**：断ち切り、枠なし、重ねゴマ、はみ出し、コマまたぎ、変形ゴマ，一条用一处，最多两处，放在情绪最需要的那一格。
- **方格不等于单调**：整条都是一样宽的横格才单调。要在「版式」里写清楚每一段的组合，以及为什么这样分。
- **一段最多两格**：三格只能是没有字或字极短的小格。有文字的格子至少占页面的八分之一。
- **画面要简单**：一张图里要放 4–6 格，信息比普通漫画的一页还密，每格的画面要更简单：一个主体，少量背景。
- **特殊处理要两边都交代**：用了特殊处理，就要按 layout-sketch 的约定在草图上标出来，也要在画面指令里写清楚。コマまたぎ、はみ出し的人物或物件，在画面指令里单独写一节（例如「### A｜跨格人物」）。

## 镜头
- **景别**：
  - 远景：地点、孤独感
  - 全景：全身动作和姿势
  - 中景：腰以上，对话
  - 近景：胸以上
  - 特写：脸，情绪
  - 大特写：眼睛、嘴、手、物件
- **一张一弛**：引き和寄り交替，相邻两格不要用一样的景别和角度。有意重复除外，比如用同一个构图表现时间流逝。场景开头可以一步步推近，结尾一步步拉远。
- **角度**：
  - 平视：克制的作品以平视为主。
  - 仰视（アオリ）：让人物显得大、有压迫感，也是孩子看大人的视角。
  - 俯视（フカン）：交代位置关系，也显得渺小、孤单。
  - 背影：藏住表情，让读者自己去想。
  - 主观视角：让读者站进角色的眼睛里。
  - 过肩镜头：适合对话。
- **轴线（イマジナリーライン）**：A 在左、B 在右，跨格不变，除非故意越轴表现关系变化。
- **构图**：主体不要正放在画面中央（日の丸構図），放在三分之一处，视线前方留空。每格只有一个焦点，背景太密就做减法。
- **镜头要写成能摆出来的位置**：
  - 写清楚：机位多高（贴地、孩子的视线高度、大人的视线高度、高处往下）、离多远、从哪个方向拍、前景挡着什么、主体在画面哪里、哪里被裁掉。
  - 不要只写「从饭桌下看街道」，要写「镜头贴地放在饭桌底下：画面上方压着桌沿和两条桌腿，前景是孩子晃着的凉鞋，远处街上一双肉色低跟鞋走近，只看得到小腿」。

## 表演（芝居）
- **一格一个瞬间**：每格只画一个定格的瞬间，选动作最有表现力的那一刻。比如伸手快碰到门把的那一下，而不是「推门走进来坐下」。
- **写动作，不写形容词**：用「动作动词 + 身体部位 + 视线落点 + 道具」来写。例：「她把杯子转了半圈，没喝，看向窗外。」不要只写「难过」「开心」「很感动」。
- **身体轮廓**：先用身体轮廓表达情绪。负面情绪往里、往下收（缩肩、低头、手收回身前），正面情绪往外放（抬头、手臂张开）。
- **手和道具**：
  - 关键情绪处一定要有手或身体的演技。手放在哪、张开还是握着、怎么拿东西，常常比脸更能说话。
  - 让道具承载心情：一直没动的碗、攥皱的纸。
- **表情强度**：按 0–3 写：0 没有表情，1 轻微（眉头、嘴角、眼皮的小变化），2 明显，3 夸张。跟着 style.md 走：克制的作品默认不超过 1，不用漫符（汗滴、红晕线、青筋）。
- **看镜头（カメラ目線）**：是很强的强调，一条最多用一次。
- **状态要连贯**：上一格攥着的衣角，下一格可以松开，但不能凭空换了动作。

## 文字
- **定稿不改**：
  - 台词和旁白用总剧本里的定稿，一字不改，不加新台词。
  - 可以把一句挪到别的格、在词组处拆成两个框，但不改字、不删。
  - 觉得文字太多，就在「自检」的「建议」里写可以删哪句，交给用户决定。
- **数量**：每格最多 2 个框；每个框最多两行、每行十来个字。长句在词组处拆开。
- **画能说清的就不用字**：旁白不重复画面。画面里在下雨，就不必写「下着雨」。把文字遮住，情绪也要读得出来。
- **框的位置**：
  - 旁白框一般在格子左上角，这一格从这里开始读。
  - 对白框贴近说话的人，尾巴指向他；先说的放左上。
  - 框不交叉，会交叉就调换人物的站位。
  - 框不能挡住脸、手和关键道具。
  - 对白框是视线的落点，可以用它把眼睛引到下一格。
- **框的种类**：圆形对白框；方形旁白框；心声用云朵形或不带尾巴的框；喊叫用锯齿形；电话、广播用闪电形尾巴。具体样式以画面总则为准。
- **拟声词和效果线**：默认不用。要用就写清为什么、字放在哪、多大、轻重。集中线、流线全条最多一处；克制的作品改用光线和背景的变化表达情绪。

## 背景和光
- **背景**：
  - 至少一格用背景交代时间和地点。
  - 情绪的近景、特写可以简化背景甚至留白，重要的人物周围留白。
  - 也可以用风景表达心情（心象風景）。
- **光线和时间**：
  - 时间和光源前后一致：傍晚的门灯、窗外的光从哪边来，跟着总剧本和上一格走。
  - 同一个背景里光线、天气的变化，可以表示时间过去了。
- **回忆**：先推近到人物的脸，再切进回忆。回忆格可以用暗角、柔和的边框，或者整体调淡。

## 写给生图模型的「画面指令」
- **这一节是给生图模型的**：它是草稿的最后一节，生图模型只看这一节，加上总剧本的画面总则和参考图。
- **长度和顺序**：每格 3–6 句，顺序是：镜头 → 画面里有谁、在哪、在做什么（表演）→ 背景和光 → 文字（类型、位置、原文）。
- **只写看得见的东西**：声音、气味、心理、前因后果都要转成画面或文字。不写理由，不写「象征」「暗示」。
- **写明画面里有谁**：
  - 每格都写明画面里有谁。
  - 主要角色只用「可用角色」里的名字称呼，不描述参考图里已有的固定长相，只写状态的变化（湿头发、卷起袖子）。
  - 衣服以总剧本「服装表」为准，画面指令里不写换衣服。只有服装表「换装」列了这一条（这一格）的，才照那一行写换成什么。
  - 要交代换了一天、过了几天，用时间标注、光线、道具和背景，不用给人换衣服：主角换了衣服，读者容易以为是另一个人。
  - 路人要写清楚衣着、发型、年龄，和主要角色明显不同。
- **少用否定句**：生图模型看到「不要画 X」反而容易画出 X。想要「没有人」，就写「空荡荡的门口」。
- **不重复画风**：不要重复画面总则里的画风设定（生成时会自动附上），只写这一格特有的东西。
- **文字写原文**：文字用引号写出原文。例：旁白框（左上）：「我们那个县城归安徽管。」对白框（右侧，尾巴指向姑姑）：「吃饭了没？」
