# 第N条 分镜草稿｜标题

## 构思
- 一句话：这一条讲什么，读完要留下什么情绪（从结尾倒推）
- 作用：在整部里是铺垫 / 推进 / 转折 / 高潮 / 余韵；接住上一条的什么，给下一条留下什么
- 视点人物：从谁的角度看；登场人物（最好不超过 3 个）和左右站位（全条不变）
- 时间地点：在哪、什么时候、天气和光
- 看点：第几格是主役のコマ（全条最大的格），为什么是这一格
- 节奏：起（第1格）→ 承 → 转 → 结；哪几格快、哪里放慢、哪一格无声；结尾是落点还是余韵
- 文字预算：对白框几个、旁白框几个
- 考虑过的方案：方案 A……；方案 B……；选了哪个，为什么

## 版式
- 共N格：一句话说整体结构（例如「上宽下窄，第4格是最大的出血格」）
- 第1格：形状、位置（整宽 / 半宽）、大约占页面多少；为什么这样分
- 第2格：……
- 阅读路径：1 → 2 → 3 …（同一行从左到右）
- 结构：节奏表分到的结构代号（A–J），这一条为什么用它
- 特殊处理：断ち切り / 枠なし / 重ねゴマ / はみ出し / コマまたぎ / 同ポジ / 変形ゴマ，用在哪一格、为了什么情绪；没有就写「方正分格」

## 逐格演出
### 第1格｜景别｜目的（交代 / 动作 / 反应 / 情绪 / 停顿）
- 镜头：景别；机位高度和角度；离人物多远；焦点
- 构图：主体在画面哪里（避开正中）；前景 / 中景 / 背景各是什么；视线和动作朝哪个方向、前方留白在哪边；文字放在哪里
- 人物：画面里有谁、各在哪（左右前后）、朝哪；定格在哪一瞬间；动作 + 身体部位 + 视线落点 + 道具；表情强度 0–3
- 背景与光：完整 / 简化 / 留白 / 用背景表达心情；时间和光源
- 文字：旁白框 / 对白（谁说）/ 心声 / 音效：原文、框的种类、位置、阅读顺序、在哪拆开
- 衔接：和下一格是同一瞬间、下一瞬间、时间跳过去还是换场；格距普通还是加宽

## 自检
- 起草时只写「待检查」；检查的那一遍再填：
- 查过：有问题的清单条目和结论，一行一条
- 改动：改了什么、为什么（一行一处；没改就写「改动：无」）
- 建议：需要用户决定的事（例如文字太多、建议删哪句），没有就不写
