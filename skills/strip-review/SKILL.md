# 检查成图

检查分两步，像编辑看原稿一样：先当第一次看的读者，看读不读得懂；再当编辑，对照分镜草稿看画得对不对。只报看得见的问题，具体到第几格、哪里不对。

## 第一步：冷读（第一次看的读者）
先不看分镜草稿，只看图 1。如果有上一条的成图，也先看上一条。用一个没读过剧本的读者的身份回答：
- 这里是哪、什么时候？和上一条比，时间、地点变了吗？变了的话看得出来吗？
- 每个人是谁、和「我」什么关系？新出现的人物，看得清脸、看得出关系吗？
- 发生了什么？每句旁白说的，和它所在那一格的画面对得上吗？
- 有没有不知道是什么意思的称呼、说法，或者不知道指什么的「它」「她」？
- 有没有看不出为什么要看的特写、插入格，或者突兀的气氛物件？
- 最后：读完这一条，读者知道了什么？

然后对照「总剧本里这一条」的读者须知：该知道的，读者知道了吗？
读不懂的地方，都作为问题报出来，kind 写「读不懂」。
- 问题出在画面上（例如姑姑只露了腿），action 选修图或重画这一格，fix 写清楚画面要怎么改（「姑姑坐在饭桌边，奶奶给她添碗」）。
- 问题出在草稿或剧本上（缺交代格、旁白放错了格、定义句被删了），fix 写「改草稿：……」或「改总剧本：……」，action 选重画这一格或整条重画。

## 第二步：对照分镜草稿
1. **版式**：格数、阅读顺序、格子形状和大小关系和版式草图一致吗？有没有画出编号、字母、虚线这些不该出现的东西？
   - 草稿里安排的特殊处理画出来了吗：断ち切り是不是延伸到了图的边，枠なし是不是没有框，重ねゴマ是不是叠在大格上，はみ出し、コマまたぎ的人物是不是压在格框上、格框在人物身后断开？
   - 这些越过格框、没有格框的画法是故意的，不要当成错误报出来。
2. **人物**：
   - 每格该在的人在不在，有没有多出来的人？
   - 同一个角色前后是不是同一个人？
   - **衣服**：每个人的衣服款式和颜色，和服装表、角色图一致吗？只有服装表「换装」列了这一条的地方才可以换；草稿写了换衣服、服装表没列，也报出来（kind 连续性，fix 写回服装表里的衣服）。台灯、夕阳下颜色偏一点不算，看得出是另一种颜色才算。
   - 路人有没有和主要角色撞衫、长得像？
3. **镜头和构图**：景别、角度、主体位置和画面指令一致吗？看点那一格最重要。
4. **表演**：指令里写的动作、视线、手、姿势画出来了吗？
5. **文字**：
   - 每个框的文字和指令一字不差吗？
   - 有没有错字、乱码、缺字，有没有多出来的字（标题、编号）？
   - 框的种类和位置对吗？全条字体字号统一吗？
6. **画风**：各格画风一致吗？和画面总则矛盾吗？
7. **手机上看**：按手机屏幕的大小看整条。字是不是小到看不清？有没有糊成一团、看不出画的是什么的格子？

## 结论
- **redo（建议重画）**：画错人或多了不该有的人、格子顺序乱了、看点那一格没画出来、文字错得多到影响阅读。
- **minor（有小问题但能用）**：构图、表情和指令有些出入，个别字有瑕疵，不影响读懂。
- **pass（可以用）**：基本按草稿画出来了。

生图本来就有偏差，不要为小出入判 redo，重画要花钱。格子高度和草图有出入（生图模型常把格子高度往平均拉）可以用修图按版式草图调，不单独作为 redo 的理由。

## 每个问题要写什么
- **panel**：第几格；整条的问题写 0。
- **area**：在图 2 坐标方格上的位置（A–F 列、1–10 行），例如 C4 或 C4:D6。要修图的问题，框住**整个要重画的东西**，不只是露出问题的那一点：笔尖碰到纸，框整只手和笔；苹果下半边有红皮，框整个苹果；衣服颜色不对，框住这件衣服。整格的问题可以不写。改字时框住整个文字框（连同框线）。
- **action**（修法），从下面四个里选一个。只有会让读者读错、让连续性断掉、让情绪落点消失、或者字写错的问题，才选修图、重画这一格、整条重画；和草稿的微小出入（手指姿势、裁切、道具差几厘米、换行位置、表情强度略有不同）一律选不用改：
  - **修图**：局部能改好的、过了上面那条门槛的问题：手脚、表情、道具、头发、光线、背景杂物、错字、格子比例。
  - **重画这一格**：这一格的镜头、构图、人物朝向整体不对，局部改不好。
  - **整条重画**：画错人、格子顺序乱了、看点格完全没画出来。
  - **不用改**：换行位置、轻微的构图出入这类不影响读懂的细节。也写出来，让用户知道。
- **fix**：写成改好以后的样子，可以直接当修图要求用。
  - 例：「第 5 格姑姑垂在身侧的右手，手指松开、自然下垂」，而不是「手不对」。
  - 改字时写出正确的原文。
  - 问题出在画面指令本身（含糊、一格塞了太多东西、自相矛盾）时，写「改草稿：第几格……怎么改」，修法选重画这一格。
